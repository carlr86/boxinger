Boxinger has two big groups: the **Team**, which decides, and the **Community**, which proposes and votes.

## Team

- **Team Admin:** the account owner, anyone with the Admin role on the team, and whoever created the board. They set up the board, invite people, import and export, and are the only ones who see who posted an anonymous idea.
- **Members:** team people with access to one or more boards. They review ideas, change statuses, prioritize and work on the Roadmap. They can post ideas if the Admin allows it.

## Community

- **Guests:** join a board with the link or an invitation. They propose ideas (if the board allows it), vote and comment.
- **Visitors:** on a public board, anyone with the link can see the ideas. To vote or comment they need to sign in.

## What each one sees

| | Community | Members | Admin |
|---|---|---|---|
| Board, Ranking, Backlog, Updates | Yes | Yes | Yes |
| Roadmap | If the Admin allows it | Yes | Yes |
| Matrix and Status | No | Yes | Yes |
| Settings | No | Partly | Yes |
| Author of an anonymous idea | No | No | Yes |

> **Tip:** The Free plan is just for you, without members. With Pro you add up to 4 members per team, with Team up to 20, and with Enterprise as many as you agree on.
